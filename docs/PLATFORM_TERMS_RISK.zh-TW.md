# 平台條款風險紀錄

更新日期：2026-10-31。這份文件記錄開發時讀到的條款和目前的做法，方便公開發布前重新檢查。**它不是法律意見，也不代表某種做法已經合法或被允許。公開發布前應找專業意見確認。**

## 讀到的條款

| 平台 | 條款重點 | 來源 |
|---|---|---|
| YouTube | 除非取得明確授權或事先書面許可，不得下載或以其他方式使用服務與內容；也不得用機器人、爬蟲等自動化工具存取服務（公開搜尋引擎的例外不適用本專案）。使用者可透過嵌入式播放器觀看。 | [YouTube 服務條款](https://www.youtube.com/t/terms?hl=zh-TW&gl=TW) |
| Bilibili | 第 5.6(3) 條：未經事先明確書面許可，不得以任何自動程式取得平台服務、內容或數據。第 1.3 條：官方公布的方式是登入和使用服務的唯一合法途徑。第 2.7 條：違規可限制功能或永久封號。 | [Bilibili 用戶協議](https://www.bilibili.com/protocal/licence.html)（2025-04-30 版） |

## 目前各功能的狀況

| 功能 | 做法 | 風險 | 公開發布前要做的事 |
|---|---|---|---|
| YouTube 字幕 | 用非官方套件 `youtube-transcript-api` 讀公開字幕 | **可能違反**自動化存取的限制，可能隨時失效或被封鎖 | 決定保留、移除或取得許可 |
| Bilibili 字幕 | 匿名呼叫未公開的網頁介面 | **可能違反**第 5.6(3) 條；沒有帳號，所以沒有封號風險 | 決定保留、移除或取得許可 |
| YouTube／Bilibili 播放 | 官方嵌入播放器 | 這是條款允許的方式，影片是否能嵌入由平台和作者決定 | 持續使用官方播放器 |
| Gemini 讀畫面 | 把公開 YouTube 網址交給 Google 的官方 API | 由使用者自備金鑰並明確開啟，影片內容由 Google 處理；Gemini 條款仍要確認 | 確認條款並保留明確告知 |
| 開發版 Whisper | `yt-dlp` 下載音訊後轉文字（桌面版不含） | **可能違反**不得下載內容的限制，只適合有權使用的影片 | 公開版不要內建；考慮是否移除 |
| 匯入 SRT／VTT | 使用者提供自己有權使用的字幕 | 權利由使用者負責 | 保留提醒文字 |
| 本地影片＋本機語音轉文字 | 使用者提供自己有權使用的影片，全程在本機處理 | 不連影片平台；權利由使用者負責 | 確認語音模型與相依套件授權 |

## 已決定不做

- **Bilibili 帳號登入或保存 Cookie**：使用者已決定不做，因為第 1.3、5.6(3) 條的風險包含帳號被封。
- **自動下載線上影片的音訊再轉文字**：違反專案規則「不下載未授權內容」。
- **錄下播放中的聲音或畫面**：雖然沒有下載檔案，仍有重製內容的疑慮。

## 可以嘗試的合規方向

- 向 Bilibili（`help@bilibili.com`）或 YouTube 申請書面許可；不一定會有回覆。
- 查 Bilibili 開放平台是否提供字幕介面；開發時沒有查到官方文件。
- YouTube Data API 的 `captions.download` 依社群回報通常只限影片擁有者，可用於使用者自己的影片；需要實際確認。
