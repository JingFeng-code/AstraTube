# AstraTube：SRT／VTT 字幕匯入指南

## 這個功能解決什麼問題？

有些 YouTube 或 Bilibili 影片沒有可匿名讀取的公開字幕。若你已經有一份**合法取得的 SRT／VTT 字幕檔**，可以匯入 AstraTube，讓影片播放器、知識卡與 AI 問答都使用該字幕，不需要擷取或下載影音。

## 使用流程

1. 在 AstraTube 首頁貼上完整的 YouTube 或 Bilibili 官方 HTTPS 影片網址。
2. 點選「匯入 SRT／VTT 字幕」並選擇檔案。檔案大小上限 **1 MB**、字幕最多 **6000 句**。
3. 確認畫面出現已匯入字幕與句數。若同一部影片已經有匯入檔案，新檔案會**取代舊檔案**。
4. **重新按「開始」**。影片知識卡與問答會優先使用匯入字幕，並非強迫走平台字幕 API。
5. 影片字幕面板顯示原文；點擊時間戳跳轉，或使用既有的免費模型／選用 Ollama 做逐句翻譯。
6. 不想再用匯入字幕時，點擊「移除已匯入字幕」。重新按「開始」後，系統會回到原本可取得的平台字幕來源。

Bilibili 多 P 影片要在 URL 上指定 `?p=N`。同一 BV 影片不同 P 的匯入字幕**互不覆蓋**。

## 字幕時間精度

- 原本平台逐字稿大多先轉成 `[整數秒] 文字`，顯示 end 秒數為**估算**。
- 這次匯入的 `.srt` 和 `.vtt` 會保留原檔案的毫秒級 start/end（例如 00:00:01,250 → 00:00:02,875）。前端讀取該值來高亮及跳轉。
- **這不代表影片播放器會保證 1 毫秒的 seek 精準度**；瀏覽器、網路、YouTube / Bilibili iframe 都可能造成差異。Bilibili 站外 iframe 目前仍無可靠的播放進度讀取。

## 資料、授權與限制

- AstraTube 不會代你下載 YouTube / Bilibili 影音，匯入檔案必須是你有權取得與使用的字幕。
- 儲存位置為執行 FastAPI 後端那台電腦的 `.cache/imported_subtitles`；如果用 Codespaces，檔案存在 Codespaces 容器，不是 Windows PC。
- 匯入檔案的文字與時間戳會保存；如果使用外部雲端 AI 產生摘要或字幕翻譯，文字也會傳送給所選供應商。使用本地 Ollama 前請確認同環境連線與模型。
- 目前是**單使用者 Web App**。匯入、狀態查詢及移除 API 尚無身分認證或不同使用者資料隔離。請保持本機或私人 Codespaces 訪問，**不能直接公開成多人共用服務**。
- 不支援音訊直接轉錄、私人影片解密、透過 Cookie 繞過平台限制；不支援超過 1 MB、6000 句及損壞時間碼的字幕。
- 程式仍未完成真人端到端驗收與 Windows 桌面安裝程式。
