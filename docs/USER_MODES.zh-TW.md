# AstraTube 一般使用者模式與開發者模式

AstraTube 以**一般使用者模式**為預設，讓不懂程式的人直接貼上 YouTube／Bilibili 網址，閱讀知識卡、AI 問答並下載 Markdown 筆記。

## 一般使用者模式（預設）

- 首次開啟不強制填 API Key；使用上游提供的免費文字模型。免費模型並非永久保證可用，服務端可能限額或變更。
- 隱藏模型選擇、Gemini 深視覺及 Codex／Claude Code 實作入口，降低操作複雜度。
- AI 問答仍然保留，且一般模式固定使用預設免費 Provider，避免無意間選到已配置的付費模型。
- 筆記可直接匯出成 Markdown 檔案，不需要先安裝 Obsidian。

## 開發者模式

設定 → 開啟「開發者模式」，即可顯示模型選單、深視覺、API Key、Obsidian 與 Codex／Claude Code 進階功能。切換開關不會清除既有模型設定；模式偏好只記在目前瀏覽器的本機儲存空間。

**安全提醒**：開發者模式只有介面切換，不是使用者身分認證、權限或防護沙箱。後端功能沒有因這個開關建立存取管制；預設的 Coding Agent 自動執行仍設為關閉。公開提供雲端服務前，必須另外實作權限、費用限制、金鑰隔離與安全稽核。

## 範圍

本次為 Web 前端的雙模式 MVP，不包含獨立 Windows 桌面安裝程式、使用者登入、多使用者帳號設定或所有影片來源的實測。
