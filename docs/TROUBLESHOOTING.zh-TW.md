# 常見錯誤訊息與處理方式

AstraTube 的錯誤訊息會盡量說出「是哪一邊出問題」與「下一步可以做什麼」。下表依畫面上看到的文字整理。

## 影片字幕

| 畫面訊息（開頭） | 代表什麼 | 你可以怎麼做 |
|---|---|---|
| 這支 YouTube 影片沒有提供公開字幕 | YouTube 明確回報這支影片沒有字幕或作者停用字幕 | 匯入你有權使用的 SRT／VTT 字幕檔，再按「開始」 |
| 無法連線到 YouTube 取得字幕 | 這台電腦連不到 YouTube（網路、Proxy、防火牆）。**影片本身可能有字幕** | 確認可以用瀏覽器開 YouTube，再按一次「開始」 |
| YouTube 暫時拒絕了字幕請求 | 短時間請求太多，或目前網路被 YouTube 限制。**影片本身可能有字幕** | 等幾分鐘或換一個網路再試；也可以先匯入字幕 |
| YouTube 表示這支影片無法播放或受到限制 | 私人、已移除、年齡或地區限制的影片 | 換一支公開影片 |
| YouTube 字幕服務回應異常 | YouTube 回應的格式不如預期，可能是平台改版 | 稍後再試；持續發生請回報開發者 |
| 這支 Bilibili 影片的字幕需要登入才能讀取 | Bilibili 只開放登入使用者讀取這支影片的字幕。AstraTube **不會**使用你的帳號登入，因為 Bilibili 用戶協議不允許未經許可以自動程式取得平台內容 | 若你有權使用字幕，在錯誤訊息下方匯入 SRT／VTT，再按「用這份字幕開始分析」；沒有字幕檔時，這支影片目前無法分析 |
| Bilibili 暫時攔截了這個請求 | Bilibili 的流量或風控限制 | 稍後再試 |
| Bilibili 影片目前不支援讀畫面 | 「讀畫面」只支援 YouTube | 不需處理，會自動改用字幕分析 |

桌面測試版**尚未內建本機語音轉錄**，所以沒有字幕的影片需要匯入字幕檔。

## AI 摘要與問答

| 畫面訊息包含 | 代表什麼 | 你可以怎麼做 |
|---|---|---|
| `HTTP 401` 或 `HTTP 403` | 模型服務拒絕存取：可能需要 API Key、金鑰無效，或目前網路／地區被限制 | 按「AI 來源」檢查金鑰，或改用其他模型、本機 Ollama |
| `HTTP 404`，或 `HTTP 400` 加上 `Model is unavailable` | 模型已下架、暫停或名稱有誤 | 按「AI 來源」重新驗證連線，改選清單中的其他模型 |
| `HTTP 429` | 額度或請求次數達到上限 | 等幾分鐘再試，或更換模型 |
| `HTTP 500`～`504` | 模型服務暫時故障 | 稍後再試 |
| `逾時` | 模型回應太久 | 稍後再試，或改用回應較快的模型 |
| `連線失敗` | 連不到模型服務 | 確認網路、Proxy、防火牆 |
| `Ollama 超過 5 分鐘沒有任何輸出` | 本機模型太大，或顯示記憶體不足而改用 CPU | 換較小的模型（例如 `qwen3:4b`）；用 `ollama ps` 確認是否為 `100% GPU`。詳見 [Ollama 說明](OLLAMA.zh-TW.md) |
| 不是有效的知識卡格式 | 模型有回應，但內容不是卡片資料（只輸出思考過程、被截斷，或不支援 JSON） | 再試一次，或更換模型 |

雲端模型由你選定的供應商提供，可用性、額度、費用與速度不受 AstraTube 控制，也可能無預警下架。AstraTube 只使用你選定的 AI 來源，失敗時會顯示原因，**不會**自動改用其他供應商；選擇 Ollama 時也不會改用雲端模型。

## 回報問題時請附上

- 畫面上的完整錯誤訊息（請勿附 API Key 或 `settings.json` 內容）
- 影片網址、Windows 版本、使用的模型名稱
