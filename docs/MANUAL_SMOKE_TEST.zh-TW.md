# AstraTube Windows 實機驗收腳本（給非工程師）

照著做大約 40～60 分鐘。每一步都有「應該看到什麼」；**和描述不同就記下來**，不用自己判斷原因。

## 開始前準備

- 一台 Windows 11（可以的話再加一台 Windows 10）
- 可以上網，並且能暫時斷網（例如關掉 Wi-Fi）
- 一支**有公開字幕**的 YouTube 影片網址（例如官方教學影片，播放器字幕按鈕可開啟 CC）
- 一支**沒有字幕**的 YouTube 影片網址
- 一個你有權使用的 `.srt` 字幕檔（可以用記事本自己寫，範例在附錄）
- 選做：已安裝 [Ollama](https://ollama.com) 並下載過一個模型（例如在命令提示字元執行 `ollama pull qwen3:4b`）

紀錄表格（每一步填 ✅／❌，❌ 請附截圖與錯誤文字）：

同時記下：Windows 版本（設定 → 系統 → 關於）、測試日期、免安裝版是從哪一次 GitHub Actions 下載的（網址）。

## A. 取得、啟動與關閉（免安裝版）

**A1　下載**
1. 到 GitHub 儲存庫 → **Actions** → **Windows desktop alpha** → 點最新一筆綠色勾勾的紀錄。
2. 頁面最下方 **Artifacts** 下載 `AstraTube-Windows-x64-portable-unsigned`。
3. 解壓縮到「文件」或「桌面」，例如 `文件\AstraTube 測試`。

應該看到：資料夾裡有 `AstraTube.exe`、`astratube-backend.exe`、`README-使用說明.txt`、`LICENSE.txt`、`THIRD_PARTY_NOTICES.md`，**沒有**安裝程式。

**A2　第一次執行**
1. 雙擊 `AstraTube.exe`。若出現「Windows 已保護您的電腦」，這是因為尚未簽章：只有在確認檔案是自己從上面步驟下載的情況下，才按「其他資訊 → 仍要執行」。**不要關閉防毒軟體。**

應該看到：10 秒內出現 AstraTube 視窗與網址輸入框，**沒有**黑色命令列視窗，也**沒有**要求安裝 Python、Node.js 或任何安裝步驟。

**A3　資料存在程式旁**
1. 回到資料夾。
2. 在檔案總管網址列分別輸入 `%APPDATA%\dev.jingfeng.astratube` 與 `%LOCALAPPDATA%\dev.jingfeng.astratube`。

應該看到：資料夾裡多了 `data\app` 與 `data\webview`；兩個 `%APPDATA%`／`%LOCALAPPDATA%` 位置都**不存在**（若之前裝過舊安裝版，記錄修改時間是否在這次測試之前）。

**A4　關閉後沒有殘留**
1. 關閉 AstraTube 視窗。
2. 等 5 秒，按 `Ctrl + Shift + Esc` 開啟工作管理員 → 「詳細資料」分頁。
3. 找 `astratube-backend.exe` 和 `AstraTube` 開頭的項目。

應該看到：**兩者都不存在**。

**A5　強制結束後沒有殘留**
1. 再開一次 AstraTube。
2. 在工作管理員「詳細資料」找到 AstraTube 主程式（不是 `astratube-backend.exe`），右鍵 → 「結束工作」。
3. 等 10 秒，再找 `astratube-backend.exe`。

應該看到：`astratube-backend.exe` 在 10 秒內自動消失。

**A6　連續開兩次**
1. 開啟 AstraTube，不要關，再雙擊一次 `AstraTube.exe`。

記錄：出現幾個視窗？兩個視窗都能用嗎？全部關閉後工作管理員是否乾淨？

**A7　放在無法寫入的位置**（選做，需要系統管理員權限才能複製）
1. 把整個資料夾複製到 `C:\Program Files\AstraTube 測試`。
2. 以一般方式（不要「以系統管理員身分執行」）雙擊其中的 `AstraTube.exe`。

應該看到：視窗開啟並說明「無法在程式所在位置建立資料夾」與建議的位置；工作管理員裡**沒有** `astratube-backend.exe`。測完刪除這個資料夾。

## B. 主要流程

開始前請先照 D3 選好 Ollama 模型，或在「AI 來源」設定自備金鑰的雲端 AI。尚未選擇時，畫面應顯示「尚未準備 AI」，不會送出分析。

**B1　分析有字幕的影片**
1. 貼上有字幕的 YouTube 網址 → 按「開始」。

應該看到：進度列顯示目前步驟與經過時間；幾分鐘內出現知識卡。若失敗，錯誤訊息要看得懂。

**B2　播放與跳轉**
1. 按播放，確認影片可以播放。
2. 點任一張知識卡或字幕的時間。

應該看到：影片跳到該時間；YouTube 播放時，目前字幕會自動標示。

**B3　整片雙語字幕**
1. 讓影片播放到中段，在字幕區按「翻譯整支影片」。
2. 翻譯中按一次「暫停」，再按「繼續翻譯」。
3. 依序點「無／原文／中文／雙語」。
4. 關閉 AstraTube 再開同一支影片。

應該看到：從目前播放位置附近開始出現台灣繁體中文，進度數字持續增加；暫停後停下、繼續後接著翻到「字幕已全部處理」。播放器下方的疊加字幕會跟著模式切換（「無」時消失），且不會擋住播放器的按鈕。重開後記得上次選的模式，已翻譯的句子不需要重翻。AI 服務忙碌時會停下並顯示原因（例如 HTTP 429），稍後按「繼續翻譯」可接續。

**B4　AI 問答**
1. 打開左下角「問影片」，問「這支影片的重點是什麼？」

應該看到：回答內容與這支影片有關。

**B5　切換影片不混用**
1. 換貼另一支有字幕的影片 → 開始。
2. 再問一次問答。

應該看到：問答紀錄是新影片自己的；回答不會提到上一支影片的內容。

**B6　匯出筆記**
1. 在知識卡上按「收進筆記」（或按鍵盤 `N`），打開右下角「筆記」→「下載 Markdown 筆記」。
2. 用記事本開啟下載的 `.md`。

應該看到：中文正常顯示，沒有亂碼；有影片連結與時間。

**B7　Bilibili（選做）**
1. 貼上一支有公開字幕的 `https://www.bilibili.com/video/BV.../` → 開始。

應該看到：產生知識卡；點時間可跳轉。畫面不會宣稱 B 站字幕會跟著播放進度自動移動（這是平台限制）。

## C. 字幕匯入

**C1　沒有字幕的影片**
1. 貼上沒有字幕的 YouTube 網址 → 開始。

應該看到：清楚的提示「請匯入 SRT／VTT 字幕」，**不是**一串英文錯誤或長時間卡住。

**C2　匯入 SRT**
1. 網址保留不變，按錯誤訊息下方的「匯入字幕檔」→ 選附錄的 `.srt`。
2. 再按「開始」。

應該看到：顯示匯入幾句；知識卡用你的字幕產生；點字幕可跳到正確時間（到毫秒）。

**C3　錯誤檔案**
1. 把一個 `.txt` 改名成 `.srt` 但內容亂打 → 匯入。

應該看到：看得懂的錯誤訊息，原本已匯入的字幕不受影響。

**C4　移除**
1. 按「分析選項」→「移除已匯入字幕」。

應該看到：狀態變成沒有匯入字幕。

## D. AI 來源與 Ollama

**D1　保留設定**
1. 按「AI 來源」選定模型後儲存，關閉 AstraTube 再打開。

應該看到：主畫面的「AI 來源」仍是之前選的模型。

**D2　Ollama 未啟動**
1. 先在工作列結束 Ollama。按「AI 來源」→ 選 Ollama →「驗證連線並取得模型」。

應該看到：「無法連線到本機 Ollama」之類的提示；**不會**自動改用其他模型。

**D3　Ollama 正常**
1. 啟動 Ollama，按「驗證連線並取得模型」。
2. 在「選擇 AI 模型」確認列出你已下載的模型，選一個後按「儲存」。
3. 分析一支有字幕的影片。

應該看到：下拉選單只出現你電腦上已下載的模型（不用自己打名稱）；結果中的模型名稱是 `Ollama/<你的模型>`。

**D4　Ollama 不會偷用雲端**
1. 模型仍選 Ollama，貼上**沒有字幕**的影片 → 開始。

應該看到：提示匯入字幕；**不會**出現 Gemini 或其他雲端模型名稱。

## E. 資料保存、離線與升級

**E1　重開後資料仍在**
1. 關閉 AstraTube 再開。

應該看到：剛才的結果、語言設定、匯入的字幕都還在。

**E2　離線**
1. 關掉 Wi-Fi → 按開始分析新影片。

應該看到：看得懂的錯誤（例如無法取得字幕）；程式不會當掉。
2. 打開 Wi-Fi → 再按一次。

應該看到：成功。

**E3　中文與空白路徑、搬移**
1. 關閉 AstraTube，把整個資料夾改名為 `AstraTube 可攜 測試`，並搬到另一個位置（例如桌面或 USB 隨身碟）。
2. 再開啟，重做 B1、B6。

應該看到：可以正常啟動；之前的設定、匯入字幕與已翻譯字幕都還在（跟著 `data` 資料夾一起搬過來）。

**E4　更新到新版**
1. 從 Actions 下載較新的免安裝版，解壓縮到新資料夾。
2. 關閉舊版，把舊版的 `data` 資料夾複製到新版資料夾。
3. 開啟新版的 `AstraTube.exe`。

應該看到：設定、匯入字幕仍在。

**E5　移除**
1. 關閉 AstraTube，刪除整個資料夾。
2. 工作管理員確認沒有 `astratube-backend.exe`。
3. 檔案總管網址列輸入 `%APPDATA%\dev.jingfeng.astratube` 與 `%LOCALAPPDATA%\dev.jingfeng.astratube`。

應該看到：都不存在（不會留下任何設定）。
