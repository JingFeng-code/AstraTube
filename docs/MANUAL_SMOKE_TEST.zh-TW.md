# AstraTube Windows 實機驗收腳本（給非工程師）

照著做大約 40～60 分鐘。每一步都有「應該看到什麼」；**和描述不同就記下來**，不用自己判斷原因。

## 開始前準備

- 一台 Windows 11（可以的話再加一台 Windows 10）
- 可以上網，並且能暫時斷網（例如關掉 Wi-Fi）
- 一支**有公開字幕**的 YouTube 影片網址（例如官方教學影片，播放器字幕按鈕可開啟 CC）
- 一支**沒有字幕**的 YouTube 影片網址
- 一個你有權使用的 `.srt` 字幕檔（可以用記事本自己寫，範例在附錄）
- 選做：已安裝 [Ollama](https://ollama.com) 並下載過一個模型（例如在命令提示字元執行 `ollama pull qwen3:4b`）

## A. 安裝與啟動

**A1　下載安裝檔**
1. 到 GitHub 儲存庫 → **Actions** → **Windows desktop alpha** → 點最新一筆綠色勾勾的紀錄。
2. 頁面最下方 **Artifacts** 下載 `AstraTube-Windows-x64-alpha-unsigned`，解壓縮得到 `.exe`。

應該看到：一個名稱含 `AstraTube` 與 `setup` 的安裝程式。

**A2　安裝**
1. 雙擊安裝程式。若出現「Windows 已保護您的電腦」，這是因為尚未簽章：只有在確認檔案是自己從上面步驟下載的情況下，才按「其他資訊 → 仍要執行」。**不要關閉防毒軟體。**
2. 依畫面完成安裝。

應該看到：開始功能表出現 AstraTube。

**A3　第一次啟動**
1. 從開始功能表開啟 AstraTube。

應該看到：10 秒內出現 AstraTube 視窗與網址輸入框，**沒有**黑色命令列視窗，也**沒有**要求安裝 Python 或 Node.js。

**A4　關閉後沒有殘留**
1. 關閉 AstraTube 視窗。
2. 等 5 秒，按 `Ctrl + Shift + Esc` 開啟工作管理員 → 「詳細資料」分頁。
3. 找 `astratube-backend.exe` 和 `AstraTube` 開頭的項目。

應該看到：**兩者都不存在**。

**A5　強制結束後沒有殘留**
1. 再開一次 AstraTube。
2. 在工作管理員「詳細資料」找到 AstraTube 主程式（不是 `astratube-backend.exe`），右鍵 → 「結束工作」。
3. 等 10 秒，再找 `astratube-backend.exe`。

應該看到：`astratube-backend.exe` 在 10 秒內自動消失。

**A6　連續開兩次**
1. 開啟 AstraTube，不要關，再從開始功能表開一次。

記錄：出現幾個視窗？兩個視窗都能用嗎？全部關閉後工作管理員是否乾淨？

## B. 一般模式主要流程（不需要任何 API Key）

**B1　分析有字幕的影片**
1. 貼上有字幕的 YouTube 網址 → 按「開始」。

應該看到：進度列顯示目前步驟與經過時間；幾分鐘內出現知識卡。若失敗，錯誤訊息要看得懂。

**B2　播放與跳轉**
1. 按播放，確認影片可以播放。
2. 點任一張知識卡或字幕的時間。

應該看到：影片跳到該時間；YouTube 播放時，目前字幕會自動標示。

**B3　整片雙語字幕**
1. 讓影片播放到中段，在字幕區按「翻譯整支影片」。
2. 翻譯中按一次「暫停」，再按「繼續翻譯」。
3. 依序點「無／原文／中文／雙語」。
4. 關閉 AstraTube 再開同一支影片。

應該看到：從目前播放位置附近開始出現台灣繁體中文，進度數字持續增加；暫停後停下、繼續後接著翻到「字幕已全部處理」。播放器下方的疊加字幕會跟著模式切換（「無」時消失），且不會擋住播放器的按鈕。重開後記得上次選的模式，已翻譯的句子不需要重翻。免費服務忙碌時會停下並顯示原因（例如 HTTP 429），稍後按「繼續翻譯」可接續。

**B4　AI 問答**
1. 打開左下角「問影片」，問「這支影片的重點是什麼？」

應該看到：回答內容與這支影片有關。

**B5　切換影片不混用**
1. 換貼另一支有字幕的影片 → 開始。
2. 再問一次問答。

應該看到：問答紀錄是新影片自己的；回答不會提到上一支影片的內容。

**B6　匯出筆記**
1. 在知識卡上按「收進筆記」（或按鍵盤 `N`），打開右下角「筆記」→「下載 Markdown 筆記」。
2. 用記事本開啟下載的 `.md`。

應該看到：中文正常顯示，沒有亂碼；有影片連結與時間。

**B7　Bilibili（選做）**
1. 貼上一支有公開字幕的 `https://www.bilibili.com/video/BV.../` → 開始。

應該看到：產生知識卡；點時間可跳轉。畫面不會宣稱 B 站字幕會跟著播放進度自動移動（這是平台限制）。

## C. 字幕匯入

**C1　沒有字幕的影片**
1. 貼上沒有字幕的 YouTube 網址 → 開始。

應該看到：清楚的提示「請匯入 SRT／VTT 字幕」，**不是**一串英文錯誤或長時間卡住。

**C2　匯入 SRT**
1. 網址保留不變，按「匯入 SRT／VTT 字幕」→ 選附錄的 `.srt`。
2. 再按「開始」。

應該看到：顯示匯入幾句；知識卡用你的字幕產生；點字幕可跳到正確時間（到毫秒）。

**C3　錯誤檔案**
1. 把一個 `.txt` 改名成 `.srt` 但內容亂打 → 匯入。

應該看到：看得懂的錯誤訊息，原本已匯入的字幕不受影響。

**C4　移除**
1. 按「移除已匯入字幕」。

應該看到：狀態變成沒有匯入字幕。

## D. 開發者模式與 Ollama（選做）

**D1　切換模式**
1. 設定 → 開啟「開發者模式」→ 確認出現模型選單。
2. 關掉再打開。

應該看到：之前選的模型仍保留。

**D2　Ollama 未啟動**
1. 先在工作列結束 Ollama。設定 → 「Ollama 本地 AI」→「測試連線並重新整理模型」。

應該看到：「無法連線到本機 Ollama」之類的提示；**不會**自動改用其他模型。

**D3　Ollama 正常**
1. 啟動 Ollama，按「測試連線並重新整理模型」。
2. 在「本地模型」下拉選單確認列出你已下載的模型，選一個後按「儲存」。
3. 在分析畫面的模型選單選 `ollama:<你的模型>` → 分析一支有字幕的影片。

應該看到：下拉選單只出現你電腦上已下載的模型（不用自己打名稱）；結果中的模型名稱是 `Ollama/<你的模型>`。

**D4　Ollama 不會偷用雲端**
1. 模型仍選 Ollama，貼上**沒有字幕**的影片 → 開始。

應該看到：提示匯入字幕；**不會**出現 Gemini 或其他雲端模型名稱。

## E. 資料保存、離線與升級

**E1　重開後資料仍在**
1. 關閉 AstraTube 再開。

應該看到：剛才的結果、語言設定、匯入的字幕都還在。

**E2　離線**
1. 關掉 Wi-Fi → 按開始分析新影片。

應該看到：看得懂的錯誤（例如無法取得字幕）；程式不會當掉。
2. 打開 Wi-Fi → 再按一次。

應該看到：成功。

**E3　中文與空白路徑**（若有另一個中文名稱的 Windows 帳號）
1. 用該帳號登入，重做 A3、B1、B6。

**E4　覆蓋安裝**
1. 從 Actions 下載較新的安裝檔，直接安裝（不先移除）。

應該看到：設定與匯入字幕仍在。

**E5　解除安裝**
1. 設定 → 應用程式 → AstraTube → 解除安裝。記錄是否有「刪除應用程式資料」選項、你選了什麼。
2. 開啟檔案總管，網址列輸入 `%APPDATA%\dev.jingfeng.astratube`。

應該看到：與你的選擇一致（選刪除則資料夾不存在）。工作管理員沒有 `astratube-backend.exe`。
